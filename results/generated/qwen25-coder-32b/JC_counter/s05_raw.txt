```verilog
module JC_counter (

    input wire rst_n,     // Active-low reset signal

        // Reset condition: Set Q to 0
        Q <= 64'b0;
    end else begin
        // Johnson counter logic
        if (Q[0] == 0) begin
            // If the least significant bit is 0, shift right and set MSB to 1
            Q <= {Q[62:0], 1'b1};

            // If the least significant bit is 1, shift right and set MSB to 0
            Q <= {Q[62:0], 1'b0};
        end
    end
end

endmodule
```

### Explanation:
- **Inputs:**
  - `clk`: Clock signal used for synchronous operation.
  - `rst_n`: Active-low reset signal to initialize the counter.
  
- **Output:**
  - `Q`: 64-bit register representing the current count value.

- **Reset Logic:**
  - When `rst_n` is low, the counter value `Q` is set to 0.
  
- **Counter Logic:**
  - On the rising edge of `clk`, the counter value is updated.
  - If the least significant bit `Q[0]` is 0, the counter increments by shifting the current value `Q[63:1]` to the right and appending a 1 at the most significant bit position.
  - If the least significant bit `Q[0]` is 1, the counter decrements by shifting the current value `Q[63:1]` to the right and appending a 0 at the most significant bit position.

This implementation ensures that the Johnson counter toggles between incrementing and decrementing based on the state of the least significant bit, creating the desired pattern.
