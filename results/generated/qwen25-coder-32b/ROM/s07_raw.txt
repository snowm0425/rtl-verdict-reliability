```verilog
    // Continuously output the data stored in the ROM at the specified address

        dout = mem[addr];
    end

endmodule
```

- **Memory Declaration**: `reg [15:0] mem [0:255];` declares a 256x16 ROM.
- **Initial Block**: The `initial` block initializes the first four memory locations with specific values. You can extend this to initialize other memory locations as needed.
- **Behavioral Block**: The `always @(*)` block ensures that `dout` is continuously updated to reflect the data stored at the address specified by `addr`.
