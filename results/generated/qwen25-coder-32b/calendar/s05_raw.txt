```verilog
always @(posedge CLK or posedge RST) begin
    if (RST) begin
        Secs <= 6'b000000;  // Reset seconds to 0
    end else if (Secs == 6'b111011) begin  // If seconds are 59
        Secs <= 6'b000000;  // Wrap around to 0

        Secs <= Secs + 1;   // Increment seconds by 1
    end

        Mins <= 6'b000000;  // Reset minutes to 0
    end else if (Mins == 6'b111011 && Secs == 6'b111011) begin  // If minutes are 59 and seconds are 59
        Mins <= 6'b000000;  // Wrap around to 0
    end else if (Secs == 6'b111011) begin  // If seconds are 59
        Mins <= Mins + 1;   // Increment minutes by 1
    end
end

always @(posedge CLK or posedge RST) begin
    if (RST) begin
        Hours <= 6'b000000;  // Reset hours to 0
    end else if (Hours == 6'b010111 && Mins == 6'b111011 && Secs == 6'b111011) begin  // If hours are 23, minutes are 59, and seconds are 59
        Hours <= 6'b000000;  // Wrap around to 0
    end else if (Mins == 6'b111011 && Secs == 6'b111011) begin  // If minutes are 59 and seconds are 59
        Hours <= Hours + 1;  // Increment hours by 1
    end
end

endmodule
```

### Explanation:
1. **Seconds Block**: 
   - The `Secs` register is incremented every clock cycle unless it reaches 59, in which case it wraps around to 0.
   - If the reset signal `RST` is active, `Secs` is set to 0.

2. **Minutes Block**:
   - The `Mins` register is incremented when `Secs` reaches 59.
   - If both `Mins` and `Secs` are 59, `Mins` wraps around to 0.
   - If the reset signal `RST` is active, `Mins` is set to 0.

3. **Hours Block**:
   - The `Hours` register is incremented when both `Mins` and `Secs` are 59.
   - If `Hours`, `Mins`, and `Secs` are all at their maximum values (23, 59, and 59 respectively), `Hours` wraps around to 0.
   - If the reset signal `RST` is active, `Hours` is set to 0.

This design ensures that the calendar counts the time correctly and resets to 00:00:00 when the reset signal is active.
