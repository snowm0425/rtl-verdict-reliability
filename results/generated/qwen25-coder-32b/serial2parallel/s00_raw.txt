This module receives a serial input signal `din_serial` along with a control signal `din_valid`, and it outputs an 8-bit parallel signal `dout_parallel` when 8 valid serial bits have been received. The `dout_valid` signal indicates the validity of the parallel output.

```verilog
module serial2parallel (
    input wire clk,          // Clock signal
    input wire rst_n,        // Reset signal (active low)
    input wire din_serial,   // Serial input data
    input wire din_valid,    // Validity signal for input data
    
    output reg [7:0] dout_parallel, // Parallel output data (8 bits wide)
    output reg dout_valid     // Validity signal for the output data
);

    reg [2:0] cnt; // 3-bit counter to count up to 8 serial bits

    // Synchronous process on the rising edge of the clock
    always @(posedge clk or negedge rst_n) begin
        if (~rst_n) begin
            // Reset state
            cnt <= 3'b000; // Reset counter
            dout_parallel <= 8'b00000000; // Clear parallel output
            dout_valid <= 1'b0; // Output is not valid
        end else if (din_valid) begin
            // Shift serial input into the parallel output register
            dout_parallel[7:1] <= dout_parallel[6:0]; // Shift left
            dout_parallel[0] <= din_serial; // Place new serial bit at least significant bit
            
            // Increment the counter
            cnt <= cnt + 1;
            
            // Check if 8 bits have been received
            if (cnt == 3'd7) begin
                cnt <= 3'b000; // Reset counter after 8 bits
                dout_valid <= 1'b1; // Output is valid
            end else begin
                dout_valid <= 1'b0; // Output is not valid
            end
        end
    end

endmodule
```

### Explanation:
1. **Inputs and Outputs:**
   - `clk`: Clock signal for synchronization.
   - `rst_n`: Active-low reset signal.
   - `din_serial`: Single-bit serial input data.
   - `din_valid`: Indicates the validity of the `din_serial` input.
   - `dout_parallel`: 8-bit parallel output data.
   - `dout_valid`: Indicates the validity of the `dout_parallel` output.

2. **Internal Register:**
   - `cnt`: A 3-bit counter to keep track of the number of serial bits received.

3. **Synchronous Process:**
   - On the rising edge of the clock or when the reset signal (`rst_n`) is active low, the process resets the counter, clears the parallel output, and sets the output validity to low.
   - When `din_valid` is high, the module shifts the current contents of `dout_parallel` one bit to the left and places the new serial bit (`din_serial`) into the least significant bit position.
   - The counter is incremented with each valid serial input.
   - When the counter reaches 7 (indicating 8 serial bits have been received), it resets the counter and sets `dout_valid` high to indicate that the parallel output is valid.

This implementation ensures that the parallel output is only valid once 8 valid serial bits have been received, and it is synchronized with the clock signal.
