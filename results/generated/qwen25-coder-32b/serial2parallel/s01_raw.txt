```verilog
module serial2parallel (
    input wire clk,
    input wire rst_n,
    input wire din_serial,
    input wire din_valid,
    output reg [7:0] dout_parallel,
    output reg dout_valid
);

    // 4-bit counter to track the number of serial input bits received
    reg [3:0] cnt;

    // Initialize the output and the counter
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            dout_parallel <= 8'b0;
            dout_valid  <= 0;
            cnt         <= 4'b0;
        end else begin
            if (din_valid) begin
                // Shift the serial input into the parallel output register
                dout_parallel <= {dout_parallel[6:0], din_serial};
                // Increment the counter
                cnt <= cnt + 1;
                // Check if 8 bits have been received
                if (cnt == 4'b111) begin
                    // Set the valid output signal
                    dout_valid <= 1;
                    // Reset the counter
                    cnt <= 4'b0;
                end else begin
                    // Reset the valid output signal
                    dout_valid <= 0;
                end
            end
        end
    end

endmodule
```

### Explanation:
1. **Inputs and Outputs:**
   - `clk`: The clock signal used for synchronization.
   - `rst_n`: The reset signal, active low. When `rst_n` is low, all internal registers are reset.
   - `din_serial`: The serial input data bit.
   - `din_valid`: Indicates the validity of the input data.
   - `dout_parallel`: The 8-bit parallel output data.
   - `dout_valid`: Indicates the validity of the output data.

2. **Internal Registers:**
   - `dout_parallel`: Holds the 8-bit parallel output data.
   - `dout_valid`: Indicates if the parallel output data is valid.
   - `cnt`: A 4-bit counter to track the number of serial input bits received.

3. **Behavioral Description:**
   - On the rising edge of `clk` or the falling edge of `rst_n`:
     - If `rst_n` is low, reset all registers.
     - If `din_valid` is high, shift the `din_serial` bit into the `dout_parallel` register from the least significant bit.
     - Increment the counter `cnt`.
     - If `cnt` reaches 7 (binary `111`), set `dout_valid` to 1 and reset `cnt` to 0.
     - Otherwise, keep `dout_valid` at 0.

This module ensures that the parallel output `dout_parallel` is valid (`dout_valid` set to 1) only after receiving 8 valid serial input bits.
