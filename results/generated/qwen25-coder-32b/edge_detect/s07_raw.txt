Sure, below is the complete Verilog code for the `edge_detect` module that detects rising and falling edges in the input signal `a` and generates corresponding output signals `rise` and `down`. The outputs are synchronized with the clock and remain set to 1 for one clock cycle after the corresponding edge is detected.

```verilog
module edge_detect (
    input clk,       // Clock signal
    input rst_n,     // Reset signal (active low)
    input a,         // Input signal
    output reg rise, // Output signal indicating a rising edge
    output reg down  // Output signal indicating a falling edge
);

    // Internal signal to store the previous value of 'a'
    reg a_prev;

    // Always block to detect rising and falling edges
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            // Reset condition: Clear both outputs and previous value
            rise <= 0;
            down <= 0;
            a_prev <= 0;
        end else begin
            // Detect rising edge
            if (!a_prev && a) begin
                rise <= 1;
            end else begin
                rise <= 0;
            end

            // Detect falling edge
            if (a_prev && !a) begin
                down <= 1;
            end else begin
                down <= 0;
            end

            // Store the current value of 'a' for the next cycle
            a_prev <= a;
        end
    end

endmodule
```

### Explanation:
- **Inputs**:
  - `clk`: The clock signal that synchronizes the edge detection.
  - `rst_n`: The reset signal that is active low. When `rst_n` is 0, the module is reset.
  - `a`: The input signal whose edges are detected.

- **Outputs**:
  - `rise`: This output signal is set to 1 for one clock cycle when a rising edge (0 to 1) is detected on `a`.
  - `down`: This output signal is set to 1 for one clock cycle when a falling edge (1 to 0) is detected on `a`.

- **Internal Signal**:
  - `a_prev`: This register stores the previous value of the input signal `a` to compare with the current value and detect edges.

- **Always Block**:
  - The always block is triggered on the positive edge of `clk` or the negative edge of `rst_n`.
  - If `rst_n` is low, the outputs `rise` and `down` are set to 0, and `a_prev` is also reset to 0.
  - If `rst_n` is high, the current value of `a` is compared with `a_prev` to detect rising and falling edges.
  - `rise` is set to 1 if a rising edge is detected, and `down` is set to 1 if a falling edge is detected.
  - After the edge detection, both `rise` and `down` are set back to 0 for the next clock cycle unless another edge is detected.
  - The current value of `a` is stored in `a_prev` at the end of each clock cycle to be used for the next comparison.

This module ensures that the edge detection is synchronized with the clock signal and that the output signals are set for only one clock cycle after the edge is detected.
