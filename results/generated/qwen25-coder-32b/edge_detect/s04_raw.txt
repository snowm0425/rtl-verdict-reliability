```verilog
module edge_detect (
    input wire clk,      // Clock signal.
    input wire rst_n,    // Reset signal (active low).
    input wire a,        // Input signal.
    output reg rise,     // Output signal indicating a rising edge.
    output reg down      // Output signal indicating a falling edge.
);

    reg a_prev;          // Previous value of input signal a.

    // Always block to update the previous value of 'a' and detect edges.
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            // Asynchronous reset (active low).
            a_prev <= 0;
            rise <= 0;
            down <= 0;
        end else begin
            // Synchronous logic to detect edges.
            a_prev <= a;
            rise <= a & ~a_prev;  // Detect rising edge.
            down <= ~a & a_prev;  // Detect falling edge.
        end
    end

endmodule
```

### Explanation:
1. **Inputs and Outputs:**
   - `clk`: Clock signal.
   - `rst_n`: Reset signal (active low).
   - `a`: Input signal to detect edges.
   - `rise`: Output signal that is 1 when a rising edge is detected.
   - `down`: Output signal that is 1 when a falling edge is detected.

2. **Internal Registers:**
   - `a_prev`: This register holds the previous value of the input signal `a` to compare with the current value and detect edges.

3. **Synchronous Logic:**
   - The `always` block is triggered on the positive edge of `clk` or on the negative edge of `rst_n`.
   - When `rst_n` is low (active low reset), all internal registers are reset to 0.
   - When `rst_n` is high, the previous value of `a` is stored in `a_prev`.
   - The `rise` signal is set to 1 if `a` is currently 1 and `a_prev` is 0 (indicating a rising edge).
   - The `down` signal is set to 1 if `a` is currently 0 and `a_prev` is 1 (indicating a falling edge).

This module ensures that the `rise` and `down` signals are synchronized with the clock and remain set to 1 only for one clock cycle when the corresponding edge is detected.
