Sure! Below is the complete Verilog code for a 3-bit comparator module named `comparator_3bit`. This module takes two 3-bit binary numbers as input and provides three outputs indicating whether the first number is greater than, equal to, or less than the second number.

```verilog
module comparator_3bit (
    input  [2:0] A,        // First 3-bit input operand
    input  [2:0] B,        // Second 3-bit input operand
    output reg A_greater,  // Output indicating if A > B
    output reg A_equal,    // Output indicating if A == B
    output reg A_less      // Output indicating if A < B
);

always @(*) begin
    // Initialize outputs
    A_greater = 0;
    A_equal   = 0;
    A_less    = 0;

    // Compare A and B
    if (A > B) begin
        A_greater = 1;
    end else if (A == B) begin
        A_equal = 1;
    end else begin
        A_less = 1;
    end
end

endmodule
```

### Explanation:
1. **Inputs and Outputs:**
   - `A [2:0]`: 3-bit input for the first binary number.
   - `B [2:0]`: 3-bit input for the second binary number.
   - `A_greater`: 1-bit output that is `1` if `A` is greater than `B`.
   - `A_equal`: 1-bit output that is `1` if `A` is equal to `B`.
   - `A_less`: 1-bit output that is `1` if `A` is less than `B`.

2. **Logic:**
   - The `always @(*)` block ensures that the logic is evaluated whenever there is a change in the inputs `A` or `B`.
   - The outputs `A_greater`, `A_equal`, and `A_less` are initialized to `0` at the beginning of each evaluation.
   - The `if-else` statements determine the relationship between `A` and `B`:
     - If `A > B`, `A_greater` is set to `1`.
     - If `A == B`, `A_equal` is set to `1`.
     - If `A < B`, `A_less` is set to `1`.

This module ensures that only one of the outputs is `1` at any given time, maintaining mutual exclusivity of the outputs.
