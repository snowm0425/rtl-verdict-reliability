This module takes two 3-bit inputs `A` and `B` and provides three 1-bit outputs: `A_greater`, `A_equal`, and `A_less`, indicating whether `A` is greater than, equal to, or less than `B`, respectively.

```verilog
module comparator_3bit (
    input [2:0] A,        // First 3-bit input operand
    input [2:0] B,        // Second 3-bit input operand
    output reg A_greater, // Output indicating if A is greater than B
    output reg A_equal,   // Output indicating if A is equal to B
    output reg A_less     // Output indicating if A is less than B
);

// Comparison logic
always @(*) begin
    if (A > B) begin
        A_greater = 1;
        A_equal = 0;
        A_less = 0;
    end else if (A == B) begin
        A_greater = 0;
        A_equal = 1;
        A_less = 0;
    end else begin
        A_greater = 0;
        A_equal = 0;
        A_less = 1;
    end
end

endmodule
```

- It has three 1-bit output ports: `A_greater`, `A_equal`, and `A_less`.
- The `always @(*)` block is a continuous assignment block that executes whenever any of the inputs (`A` or `B`) change.
- Inside this block, the values of `A_greater`, `A_equal`, and `A_less` are set based on the comparison of `A` and `B`:
  - If `A` is greater than `B`, `A_greater` is set to 1, and the other two outputs are set to 0.
  - If `A` is equal to `B`, `A_equal` is set to 1, and the other two outputs are set to 0.
