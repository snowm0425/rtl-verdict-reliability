This LFSR uses the XOR of the most significant bit (out[3]) and the second most significant bit (out[2]) to generate the feedback, which is then inverted and inserted into the least significant bit (LSB) on each rising edge of the clock. The register is reset to zero when the reset signal (rst) is high.

```verilog
module LFSR (
    input clk,          // Clock signal
    input rst,          // Active high reset signal
    output reg [3:0] out // 4-bit output
);

always @(posedge clk or posedge rst) begin
    if (rst) begin
        // Initialize the register to zero on reset
        out <= 4'b0000;
    end else begin
        // Calculate the feedback bit
        reg feedback;
        feedback = ~(out[3] ^ out[2]); // XOR out[3] and out[2], then invert
        
        // Shift the register left and insert the feedback bit at the LSB
        out <= {out[2:0], feedback};
    end
end

endmodule
```

### Explanation:
- **Reset Condition (`rst`)**: When the reset signal is high, the register `out` is set to `4'b0000`.
- **Feedback Calculation**: The feedback bit is calculated by XORing `out[3]` and `out[2]`, and then inverting the result.
- **Shifting and Insertion**: On the rising edge of the clock, the register is shifted left (`out[2:0]` moves to `out[3:1]`), and the feedback bit is inserted into `out[0]` (the least significant bit).
