The LFSR shifts its bits to the left on the rising edge of the clock signal, and the feedback is generated by inverting the XOR of the two most significant bits (out[3] and out[2]).

```verilog
module LFSR (
    input wire clk,          // Clock signal
    input wire rst,          // Active high reset signal
    output reg [3:0] out     // 4-bit output
);

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            // Initialize the register to zero on reset
            out <= 4'b0000;
        end else begin
            // Calculate the feedback value
            reg feedback;
            feedback = ~(out[3] ^ out[2]);
            
            // Shift the register left and insert the feedback at the LSB
            out <= {out[2:0], feedback};
        end
    end

endmodule
```

### Explanation:
- **Module Declaration**: The module is named `LFSR` and has three ports: `clk`, `rst`, and `out`.
- **Clock and Reset**: The `always` block is triggered on the rising edge of `clk` or `rst`.
- **Reset Operation**: When `rst` is high, the register `out` is set to 4'b0000 (all zeros).
- **Feedback Calculation**: The feedback is calculated by inverting the XOR of `out[3]` and `out[2]`.
- **Shifting Operation**: On the rising edge of the clock (and no reset), the bits in the register are shifted left, and the feedback value is inserted at the least significant bit (LSB).

This implementation ensures that the LFSR generates a pseudo-random sequence based on the specified feedback mechanism.
