```verilog
module right_shifter (
    input clk,  // Clock signal used for synchronous operation
    input d,    // Input signal to be right-shifted
    output reg [7:0] q  // Output signal representing the result of the right shift operation
);

// Initialize the q register to 0
initial begin
    q = 8'b0;
end

// On each rising edge of the clock, perform the right shift operation
always @(posedge clk) begin
    // Right shift the contents of q by 1 bit and insert the new input bit d into the most significant position
    q <= {d, q[7:1]};
end

endmodule
```

### Explanation:
1. **Module Declaration**:
   - `right_shifter` is the name of the module.
   - It has three ports: `clk` (input), `d` (input), and `q` (output).

2. **Register Initialization**:
   - The register `q` is defined as an 8-bit vector (`reg [7:0] q`).
   - The `initial` block sets `q` to 0 when the simulation starts.

3. **Right Shift Operation**:
   - The `always @(posedge clk)` block ensures that the operations inside it are triggered on the rising edge of the clock.
   - `q <= {d, q[7:1]};` performs the right shift operation:
     - `{d, q[7:1]}` creates a new 8-bit vector where the most significant bit is the input `d` and the remaining bits are the current bits of `q` shifted right by one position.

This module will take a 1-bit input `d` and right-shift an 8-bit register `q` on each rising edge of the clock, inserting the new input bit into the most significant position.
