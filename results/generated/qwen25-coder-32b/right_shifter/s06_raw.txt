```verilog
module right_shifter (
    input clk,    // Clock signal used for synchronous operation
    input d,      // Input signal to be right-shifted
    output reg [7:0] q  // Output signal representing the result of the right shift operation
);

// Initialize the register q to 0
initial begin
    q = 8'b0;
end

// On each rising edge of the clock, perform the right shift operation
always @(posedge clk) begin
    q <= (q >> 1);  // Right shift the contents of q by 1 bit
    q[7] <= d;      // Insert the new input bit d into the most significant position of q
end

endmodule
```

### Explanation:
- **Module Declaration**: The module is named `right_shifter` with three ports: `clk`, `d`, and `q`.
- **Register Initialization**: The register `q` is initialized to `8'b0` using the `initial` block. This ensures that `q` starts with all zeros.
- **Synchronous Logic**: The `always @(posedge clk)` block ensures that the operations inside it are executed on each rising edge of the clock signal.
  - **Right Shift Operation**: `q <= (q >> 1)` shifts the bits of `q` to the right by one position.
  - **Insert New Input**: `q[7] <= d` sets the most significant bit (MSB) of `q` to the value of the input signal `d`.

This module will effectively perform the right shift operation as described, with the new input bit being inserted into the most significant bit position of the register on each clock cycle.
