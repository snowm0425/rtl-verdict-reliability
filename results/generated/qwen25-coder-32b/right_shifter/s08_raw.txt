```verilog
module right_shifter (
    input clk,  // Clock signal used for synchronous operation
    input d,    // Input signal to be right-shifted
    output reg [7:0] q  // Output signal representing the result of the right shift operation
);

// Initialize the register q to 0
initial begin
    q = 8'b0;
end

// On each rising edge of the clock, perform the right shift and insert the new input bit
always @(posedge clk) begin
    q <= {d, q[7:1]};  // Shift q to the right and insert d into the MSB position
end

endmodule
```

### Explanation:
- **Module Declaration:** The module `right_shifter` is declared with three ports: `clk`, `d`, and `q`.
- **Initialization:** The `initial` block sets the register `q` to 0 at the start of the simulation.
- **Always Block:** The `always @(posedge clk)` block ensures that the operations inside it are executed on each rising edge of the clock.
- **Right Shift and Insertion:** The expression `{d, q[7:1]}` concatenates the input `d` with the lower 7 bits of `q`, effectively right-shifting `q` by one bit and inserting `d` into the most significant bit (MSB) position.

This code will correctly perform an 8-bit right shift on the input signal `d` and output the result through `q`.
