```verilog
module synchronizer (
    input wire clk_a,        // Clock signal A
    input wire clk_b,        // Clock signal B
    input wire arstn,        // Active-low reset signal A
    input wire brstn,        // Active-low reset signal B
    input wire [3:0] data_in, // Input data signal
    input wire data_en,      // Input enable signal
    output reg [3:0] dataout // Output data signal
);

    reg [3:0] data_reg;      // Register to store input data
    reg en_data_reg;          // Register to store enable signal
    reg en_clap_one;          // First enable control register
    reg en_clap_two;          // Second enable control register

    // Data and enable register update on clk_a
    always @(posedge clk_a or negedge arstn) begin
        if (!arstn) begin
            data_reg <= 4'b0;    // Reset data_reg to 0
            en_data_reg <= 1'b0; // Reset en_data_reg to 0
        end else begin
            data_reg <= data_in; // Update data_reg with data_in
            en_data_reg <= data_en; // Update en_data_reg with data_en
        end
    end

    // Enable control registers update on clk_b
    always @(posedge clk_b or negedge brstn) begin
        if (!brstn) begin
            en_clap_one <= 1'b0; // Reset en_clap_one to 0
            en_clap_two <= 1'b0; // Reset en_clap_two to 0
        end else begin
            en_clap_one <= en_data_reg; // Update en_clap_one with en_data_reg
            en_clap_two <= en_clap_one; // Update en_clap_two with previous en_clap_one
        end
    end

    // Output assignment on clk_b
    always @(posedge clk_b or negedge brstn) begin
        if (!brstn) begin
            dataout <= 4'b0; // Reset dataout to 0
        end else if (en_clap_two) begin
            dataout <= data_reg; // Assign dataout with data_reg if en_clap_two is active
        end
        // else dataout retains its previous value
    end

endmodule
```

### Explanation:
1. **data_reg**: This register stores the input data `data_in` and is updated on the rising edge of `clk_a` or when `arstn` is low.
2. **en_data_reg**: This register stores the enable signal `data_en` and is updated on the rising edge of `clk_a` or when `arstn` is low.
3. **en_clap_one** and **en_clap_two**: These two registers are used to delay the enable signal by two clock cycles of `clk_b`. `en_clap_one` is updated with the value of `en_data_reg` on the rising edge of `clk_b`, and `en_clap_two` is updated with the previous value of `en_clap_one`.
4. **dataout**: This is the final output. It is updated on the rising edge of `clk_b`. If `en_clap_two` is active (high), `dataout` is assigned the value of `data_reg`. Otherwise, `dataout` retains its previous value.

This design ensures that the data is synchronized correctly between the two clock domains and that the enable signal is properly delayed to meet the specified conditions.
