```verilog
module counter_12 (

    if (!rst_n) begin
        // Reset the counter to 0 when reset is active
        out <= 4'b0000;
    end else if (valid_count) begin
        // Increment the counter if valid_count is active
        if (out == 4'd11) begin

            // Increment the counter
            out <= out + 1;
        end
    end
    // If valid_count is 0, the counter remains unchanged
end

endmodule
```

### Explanation:
- **Reset (`rst_n`)**: The counter is reset to `4'b0000` when `rst_n` is low (active).
- **Clock (`clk`)**: The counter is synchronous with the rising edge of the clock signal.
- **Valid Count (`valid_count`)**: 
  - When `valid_count` is `1`, the counter increments.
  - If the counter reaches `4'd11`, it wraps around to `4'b0000`.
  - If `valid_count` is `0`, the counter remains unchanged.
- **Output (`out`)**: The current count value is output as a 4-bit register.
