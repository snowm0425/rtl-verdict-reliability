```verilog
module counter_12 (
    input  rst_n,        // Reset signal (active low)
    input  clk,          // Clock signal
    input  valid_count,  // Signal to enable counting
    output [3:0] out     // 4-bit output representing the current count value
);

    // Register to store the current count value
    reg [3:0] count;

    // Continuous assignment to the output port
    assign out = count;

    // Always block for synchronous logic
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            // Reset condition: active low reset
            count <= 4'b0000;
        end else if (valid_count) begin
            // Counting condition: increment if valid_count is high
            if (count == 4'd11) begin
                // Wrap around to 0 when count reaches 11 (4'd11)
                count <= 4'b0000;
            end else begin
                // Increment the count
                count <= count + 1;
            end
        end
        // If valid_count is low, the count remains unchanged
    end

endmodule
```

### Explanation:
- **Inputs:**
  - `rst_n`: Active low reset signal. When this signal is 0, the counter is reset to 0.
  - `clk`: Clock signal. The counter logic is synchronized to the rising edge of this signal.
  - `valid_count`: Signal to enable counting. When this signal is 1, the counter increments on each clock cycle.

- **Outputs:**
  - `out`: 4-bit output port representing the current count value.

- **Internal Logic:**
  - The `count` register stores the current count value.
  - The `always` block handles the synchronous logic:
    - On the rising edge of `clk` or the falling edge of `rst_n`:
      - If `rst_n` is 0, `count` is reset to 4'b0000.
      - If `valid_count` is 1, `count` is incremented by 1. If `count` reaches 4'd11, it wraps around to 4'b0000.
      - If `valid_count` is 0, `count` remains unchanged.

This module will meet the specified requirements for counting from 4'b0000 to 4'd11 and controlling the counting process with the `valid_count` signal.
