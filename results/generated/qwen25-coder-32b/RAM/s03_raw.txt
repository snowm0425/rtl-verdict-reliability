```verilog
module RAM (

    input wire read_en,      // Read enable signal to initiate a read operation.

);

    parameter WIDTH = 6;
    parameter DEPTH = 8;

    // RAM array declaration
    reg [WIDTH-1:0] RAM [DEPTH-1:0];

    // Initialization of the RAM array to 0 on reset
    initial begin
        for (integer i = 0; i < DEPTH; i = i + 1) begin
            RAM[i] <= 0;
        end
    end

    // Write operation
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            // Clear all memory locations on reset
            for (integer i = 0; i < DEPTH; i = i + 1) begin
                RAM[i] <= 0;
            end
        end else if (write_en) begin
            // Write data to the RAM array at the specified address
            RAM[write_addr] <= write_data;
        end
    end

    // Read operation
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            // Clear read_data on reset
            read_data <= 0;
        end else if (read_en) begin
            // Read data from the RAM array at the specified address
            read_data <= RAM[read_addr];
        end else begin
            // Clear read_data if read_en is not active
            read_data <= 0;
        end
    end

endmodule
```

### Explanation:
1. **Parameters**:
   - `WIDTH` is set to 6, indicating the bit width of each memory location.
   - `DEPTH` is set to 8, indicating the number of memory locations.

2. **RAM Array**:
   - `RAM` is a 2D register array with 8 rows (depth) and 6 columns (width).

3. **Initialization**:
   - The `initial` block sets all memory locations to 0 during initialization.

4. **Write Operation**:
   - The `always` block triggered on the positive edge of the clock (`posedge clk`) or the negative edge of the reset (`negedge rst_n`) handles the write operation.
   - On reset, all memory locations are cleared to 0.
   - If `write_en` is active, the data (`write_data`) is written to the RAM at the specified address (`write_addr`).

5. **Read Operation**:
   - Another `always` block handles the read operation.

   - If `read_en` is active, the data at the specified address (`read_addr`) is read from the RAM and assigned to `read_data`.
   - If `read_en` is not active, `read_data` is cleared to 0.

This module allows simultaneous read and write operations, making it a dual-port RAM.
