```verilog
module RAM (
    input clk,          // Clock signal
    input rst_n,        // Active-low reset signal
    input write_en,     // Write enable signal
    input [2:0] write_addr, // Write address (3 bits for 8 locations)
    input [5:0] write_data, // Write data (6 bits)
    input read_en,      // Read enable signal
    input [2:0] read_addr,  // Read address (3 bits for 8 locations)
    output reg [5:0] read_data // Read data (6 bits)
);

    parameter WIDTH = 6;
    parameter DEPTH = 8;

    // RAM array declaration
    reg [WIDTH-1:0] RAM [DEPTH-1:0];

    // Initialize RAM to 0 on reset
    initial begin
        for (integer i = 0; i < DEPTH; i = i + 1) begin
            RAM[i] = {WIDTH{1'b0}};
        end
    end

    // Write operation
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            // Clear all memory locations on reset
            for (integer i = 0; i < DEPTH; i = i + 1) begin
                RAM[i] <= {WIDTH{1'b0}};
            end
        end else if (write_en) begin
            // Write data to the specified address
            RAM[write_addr] <= write_data;
        end
    end

    // Read operation
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            // Clear read_data on reset
            read_data <= {WIDTH{1'b0}};
        end else if (read_en) begin
            // Read data from the specified address
            read_data <= RAM[read_addr];
        end else begin
            // Clear read_data if read_en is not active
            read_data <= {WIDTH{1'b0}};
        end
    end

endmodule
```

### Explanation:

1. **Module Definition**:
   - The module `RAM` has input and output ports as specified.
   - `write_addr` and `read_addr` are 3 bits wide because the depth of the RAM is 8, which requires \( \log_2(8) = 3 \) bits to address all locations.

2. **RAM Array**:
   - `RAM` is a 2D array where each element is a 6-bit register. The array size is 8 (DEPTH) by 6 (WIDTH).

3. **Initialization**:
   - The `initial` block sets all RAM locations to 0 when the simulation starts.

4. **Write Operation**:
   - The first `always` block handles the write operation.
   - On the negative edge of `rst_n`, all memory locations are cleared.
   - On the positive edge of `clk` and if `write_en` is high, the data at `write_addr` is updated with `write_data`.

5. **Read Operation**:
   - The second `always` block handles the read operation.
   - On the negative edge of `rst_n`, `read_data` is cleared.
   - On the positive edge of `clk` and if `read_en` is high, `read_data` is assigned the value from the memory location specified by `read_addr`.
   - If `read_en` is low, `read_data` is cleared.

This implementation ensures that read and write operations can occur concurrently without interfering with each other.
