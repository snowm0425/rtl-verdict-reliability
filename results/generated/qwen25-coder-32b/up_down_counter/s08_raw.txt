```verilog
module up_down_counter (
    input wire clk,          // Clock signal
    input wire reset,        // Reset signal
    input wire up_down,      // Control signal for direction
    output reg [15:0] count  // 16-bit counter output
);

// Synchronous process triggered by the rising edge of the clock signal
always @(posedge clk) begin
    if (reset) begin
        // If reset is active, set count to 0
        count <= 16'b0;
    end else begin
        // Determine the counting direction based on the up_down signal
        if (up_down) begin
            // If up_down is 1, increment the counter
            count <= count + 1;
        end else begin
            // If up_down is 0, decrement the counter
            count <= count - 1;
        end
    end
end

endmodule
```

### Explanation:
- **Inputs:**
  - `clk`: The clock signal that synchronizes the counting process.
  - `reset`: An active-high reset signal that resets the counter to zero.
  - `up_down`: A control signal that determines the counting direction. When `up_down` is 1, the counter increments; when `up_down` is 0, it decrements.

- **Output:**
  - `count[15:0]`: A 16-bit register that holds the current value of the counter.

- **Functionality:**
  - The `always @(posedge clk)` block ensures that the counter logic is triggered on the rising edge of the clock.
  - If the `reset` signal is high, the counter is reset to 0.
  - If the `up_down` signal is high, the counter increments by 1.
  - If the `up_down` signal is low, the counter decrements by 1.

This code will synthesize a 16-bit up-down counter that operates based on the provided control signals.
