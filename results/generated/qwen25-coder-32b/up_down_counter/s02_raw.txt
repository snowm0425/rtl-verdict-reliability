```verilog
module up_down_counter (

);

        // Reset the counter to zero if reset is active
        count <= 16'b0;
    end else begin

        if (up_down) begin
            // Increment the counter if up_down is high
            count <= count + 1;
        end else begin
            // Decrement the counter if up_down is low
            count <= count - 1;
        end
    end
end

endmodule
```

- **Reset Condition**: When the `reset` signal is active (high), the counter is reset to 0 (`16'b0`).
- **Counting Logic**: The counter increments if `up_down` is high and decrements if `up_down` is low.
- **Data Type**: The `count` register is declared as a 16-bit vector (`reg [15:0]`) to store the current counter value.
