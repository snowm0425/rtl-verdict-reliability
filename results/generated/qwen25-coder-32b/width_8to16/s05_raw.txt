This module handles the conversion of an 8-bit input to a 16-bit output by concatenating two consecutive 8-bit inputs. The `valid_out` and `data_out` are generated only after receiving two valid 8-bit inputs.

```verilog
module width_8to16 (
    input wire clk,         // Clock signal
    input wire rst_n,       // Active-low reset signal
    input wire valid_in,    // Validity of the input data
    input wire [7:0] data_in, // 8-bit input data

    output reg valid_out,   // Validity of the output data
    output reg [15:0] data_out // 16-bit output data
);

    // Internal register to store the first 8-bit data
    reg [7:0] data_lock;
    
    // Flag to indicate if the first data has been stored
    reg first_data_stored;

    // Synchronous reset and update logic
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            // Reset condition: clear all registers and flags
            data_out <= 16'b0;
            valid_out <= 1'b0;
            data_lock <= 8'b0;
            first_data_stored <= 1'b0;
        end else if (valid_in) begin
            if (!first_data_stored) begin
                // Store the first 8-bit data
                data_lock <= data_in;
                first_data_stored <= 1'b1;
                valid_out <= 1'b0;
            end else begin
                // Concatenate the stored data with the new data to form 16-bit output
                data_out <= {data_lock, data_in};
                valid_out <= 1'b1;
                // Reset the flag for the next pair of data
                first_data_stored <= 1'b0;
            end
        end else begin
            // If no valid input, maintain the state
            valid_out <= 1'b0;
        end
    end

endmodule
```

### Explanation:
- **Registers:**
  - `data_out`: Holds the 16-bit concatenated output data.
  - `valid_out`: Indicates the validity of the `data_out`.
  - `data_lock`: Temporarily stores the first 8-bit input data.
  - `first_data_stored`: A flag to indicate whether the first 8-bit data has been stored.

- **Reset:**
  - On a negative edge of `rst_n`, all registers and flags are cleared to their initial state.

- **Data Handling:**
  - When `valid_in` is high, the module checks the `first_data_stored` flag.
  - If `first_data_stored` is low, it stores the incoming 8-bit data in `data_lock` and sets the flag.
  - If `first_data_stored` is high, it concatenates the stored `data_lock` with the incoming `data_in` to form `data_out`, sets `valid_out` high, and resets the flag for the next pair of data.

This module ensures that `valid_out` and `data_out` are only generated after two valid 8-bit inputs are received.
