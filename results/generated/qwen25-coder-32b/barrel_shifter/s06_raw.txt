### Submodule: mux2X1
This submodule selects between two 8-bit inputs based on a 1-bit select signal.

```verilog
module mux2X1 (
    input [7:0] in0,
    input [7:0] in1,
    input sel,
    output [7:0] out
);
assign out = sel ? in1 : in0;
endmodule
```

### Module: barrel_shifter
This is the main module that performs the barrel shifting based on the control signal.

```verilog
module barrel_shifter (
    input [7:0] in,
    input [2:0] ctrl,
    output [7:0] out
);
    // Intermediate signals for each stage of the barrel shifter
    wire [7:0] shift4;
    wire [7:0] shift4_2;
    wire [7:0] shift4_2_1;

    // Shift by 4 positions
    assign shift4 = {in[3:0], in[7:4]}; // Logical right shift by 4 positions

    // First mux to select between original input and shifted by 4 positions
    mux2X1 mux1 (
        .in0(in),
        .in1(shift4),
        .sel(ctrl[2]),
        .out(shift4_2)
    );

    // Shift by 2 positions
    assign shift4_2[7:0] = {shift4_2[5:0], shift4_2[7:6]}; // Logical right shift by 2 positions

    // Second mux to select between previous result and shifted by 2 positions
    mux2X1 mux2 (
        .in0(shift4_2),
        .in1(shift4_2[7:0] << 2), // Logical left shift by 2 positions
        .sel(ctrl[1]),
        .out(shift4_2_1)
    );

    // Shift by 1 position
    assign shift4_2_1[7:0] = {shift4_2_1[6:0], shift4_2_1[7]}; // Logical right shift by 1 position

    // Third mux to select between previous result and shifted by 1 position
    mux2X1 mux3 (
        .in0(shift4_2_1),
        .in1(shift4_2_1 << 1), // Logical left shift by 1 position
        .sel(ctrl[0]),
        .out(out)
    );
endmodule
```

### Explanation:
1. **Shift by 4 Positions**: The input is shifted by 4 positions to the right using a concatenation of the lower and upper nibbles.
2. **Shift by 2 Positions**: The intermediate result from the previous stage is shifted by 2 positions. The direction of the shift (left or right) is determined by the `ctrl[1]` signal.
3. **Shift by 1 Position**: The intermediate result from the previous stage is shifted by 1 position. The direction of the shift (left or right) is determined by the `ctrl[0]` signal.
4. **Mux2X1 Submodule**: This submodule is used to select between the original input and the shifted input at each stage based on the control signal.

This implementation efficiently performs the barrel shifting using a combination of logical shifts and multiplexers.
