### mux2X1 Submodule
This submodule is a simple 2-to-1 multiplexer.

```verilog
module mux2X1 (
    input sel,
    input [7:0] in0,
    input [7:0] in1,
    output [7:0] out
);
assign out = sel ? in1 : in0;
endmodule
```
